## 🚀 Software Development Projects

### 1. BrightStart – Educational Learning Platform

**Technologies:** React.js, Java, Spring Boot, PostgreSQL

**Project Repositories:**
- [Frontend Repository](https://github.com/Mhlana17/BrightStart)
- [Backend Repository](https://github.com/Mhlana17/backendBrightStart-compatible)

**Project Overview:**

BrightStart is an educational learning platform designed to support learners through accessible educational programmes and lesson bookings.

The application includes functionality for user registration, authentication, lesson bookings, programme management, and learner progress tracking.

**Key Development Areas:**
- Frontend development using React.
- Backend development using Java and Spring Boot.
- Database integration and management.
- User registration and login functionality.
- Lesson booking and programme management.
- Learner progress management.

### 2. AnimeStore – E-commerce Application

**Technologies:** React.js, JavaScript, Java and backend development technologies.

**Project Repositories:**
- [AnimeStore Frontend](https://github.com/Mhlana17/animestoref)
- [AnimeStore Backend](https://github.com/Mhlana17/AnimeStoreBackend1)

**Project Overview:**

AnimeStore is an e-commerce application designed to provide users with an online platform to browse and purchase anime-related products.

The project focuses on implementing common e-commerce functionality and connecting frontend and backend components.

**Key Development Areas:**
- Product browsing and management.
- User authentication.
- Shopping cart functionality.
- Frontend and backend integration.
- Application functionality and user experience.

### 3. Community Store – Online Marketplace

**Project Repository:**
- [Community Store on GitHub](https://github.com/Mhlana17/communityStore)

**Project Overview:**

Community Store is a software development project focused on creating an online marketplace that connects buyers and sellers.

The project provides an opportunity to apply software development concepts, project planning, teamwork, and application design to a practical marketplace solution.

**Key Areas:**
- Marketplace application development.
- Buyer and seller functionality.
- User and administrator functionality.
- Project planning and development.
- Problem-solving and collaboration.
